# Learning-how-to-make-sites-space
So the algorithm of making pull requests is:
1. Create a branch with the command git branch -m name
2. index all your files with command git add .
3. create and name commit with command git commit -m name we also can use git commit -a -m to index all files and make commit at the same time
4. push the commit with git push origin branch name
5. then switch on github and create a pull request
6. check the update and merge it with the main branch
7. use git pull to update your data in local repository
8. so if you want to change anything in your commit you just change the code whithout switching branch and use points 2,3 and 4
